 Pullback Algorithm
========================================================
Current Scenario (When Batch submitted to PCI)
- Pullback only can be requested when batch is submitted to PCI(i.e Batch PipelineStatus = "Submitted")
- Cannot pullback in below scenario/mailpiece status
	-Pullback already Requested
	-mailpiece status are "Aborted", "PulledBack", "Error", "Shipped"
	-Batch pipeline Status are "Received","Downloaded"
- Can not pullback whole batch (we have to select all mailpiece for the particular batch to pullback whole batch)
- when Batch PipelineStatus = "Submitted" and MailPieceStatus = "InProgress" then generate pullback Request form and email to PCI.
- After generating form update "PullBackRequestedOn" in AM.MailPiece table and insert data into PullbackRequested table.
========================================================
New scenario
- Pullback should also work even if batch is not submitted to PCI 

- When Batch is not submitted to PCI
