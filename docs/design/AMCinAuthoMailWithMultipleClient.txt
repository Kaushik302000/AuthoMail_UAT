AMC With Multiple Client Algorithm :

- Challange : How to handle multiple clients from AMC in AuthoMail?

Sagar's Thought Process - 1 :
1) Create AMC as a client in AuthoMail
2) Maintain ClientCode and ClientId Mapping table for AMC
3) In Console Process
	- Download batch as AMC Batch
	- In Separation Stage
		- Check for Received ClientCode and Mapped ClientCode
		- Separate other client codes and generate new XML for mapped clients
	- In Validation Stage
		- Save each mail piece with mapped client
			- Challange : Need to maintain Validation conditions client wise
			- Challange : What to do with Mail Piece which does not contains ClientCode attribute?
	- In Acknowledgement Stage		
		- Generate Immediate Error Report as per AMC standard but need to generate client wise
		- Generate and sent Acknowledgement client wise for particular batch
			- Challange :  What to do with Mail Piece which does not contains ClientCode attribute? To whome need to send that mail piece as an error?
4) In Core Process
	- In Prepped Stage
		- Need to process each and every mail piece using MailPiece client id
		- If any Error in Mail Pieces then Generate Immediate Error Report client wise (Need to do in AMC client only)
	- In Submitted To Shipping Stage
		- We don't need to go in this stage because we are going to create separate application to generate sweep time wise batch
		- So Flow did not change in this stage for other clients
	- In Submitted Response Received Stage 
		- Create one folder where every response will be copied because we are grouping all same doctype's mail pieces of multiple mail batches. So we cannot identify batches from it.
			- Challange : How we will manage single response for multiple batches?
	- In Process Received Response
		- Take each response by PrintBatchId and update value according to response of particular mail piece
		- After receiving whole response we can update batch status.
	- In Report Prepped Stage
		- Generate client wise report of batches but with same format of AMC
			- Challange : May need to add client code in each report to identify for which client it is.
5) In Reported Back Process
	- While looking for reports in folder we have generated, we can notify and generate production summary for each client.
		- Challange : While uploading to AMC SFT site, we may need to change its name because of required naming convention as per AMC.
